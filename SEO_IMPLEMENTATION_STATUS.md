# PromSafe 2.0 – SEO implementation status

Дата фиксации: 18.09.2026
География: Москва и Московская область

## Реализовано в коде

1. Уникальные SEO Title и Description для:
   - главной;
   - каталога услуг;
   - всех 10 услуг;
   - каталога решений;
   - всех 6 отраслевых решений;
   - базы знаний;
   - всех 5 текущих статей;
   - калькулятора;
   - бесплатных материалов и чек-листа ГИТ;
   - страницы компании;
   - контактов.

2. Canonical URL на индексируемых страницах.
3. Open Graph / базовые social metadata.
4. JSON-LD:
   - Organization + WebSite глобально;
   - Service для страниц услуг и отраслевых решений.
5. sitemap.xml расширен и приведён к текущим URL.
6. robots.txt:
   - staging/local закрыты от индексации;
   - production разрешён и содержит sitemap + host.
7. Усилена внутренняя перелинковка:
   - услуга → профильная статья / чек-лист / отрасль;
   - статья → соответствующая услуга;
   - отрасль → услуги и материалы;
   - footer → ключевые коммерческие страницы.
8. Основные коммерческие страницы локализованы под Москву и Московскую область без создания дублирующих doorway-страниц.
9. H1 основных каталогов и ключевых решений уточнены под поисковый интент.
